04 · Tres formas de uso

Del caso completo a la fuente de datos

A

El simulador es el curso

El caso ya trae la estructura: cada fase acompaña una unidad del temario. Es la forma natural para las dos asignaturas de aplicación directa.

B

El simulador es un módulo

Se inserta en las sesiones que el docente ya tiene para su tema, por ejemplo solo lo territorial con TerriTek. El resto del curso sigue igual.

C

El simulador es la fuente de datos

Los entregables de un caso ya resuelto —una conciliación fiscal, unos papeles de trabajo— se usan como caso base en clase.

La duración la fija cada simulador (lámina 04) y el docente decide el peso en la nota.

PraxiLab en UManizales · Mapeo curricular · 09

Las tres formas describen cómo se integra el simulador a un curso que ya existe, no una carga adicional para el docente. La forma A es la natural para Auditoría y aseguramiento y Derecho tributario procedimental. La B, para Derecho tributario sustantivo y Contabilidad ambiental. La C sirve para llevar a otras asignaturas el material que produjo un caso ya jugado.
